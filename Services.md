#### **Services Required:**





###### &#x20;    Azure Service	                     Purpose in the Project

Azure Resource Group	        Organizes and manages all project resources

Azure Virtual Network (VNet)	Provides the private network environment

Azure Subnet	                Provides a private network segment for the VM

Azure NAT Gateway	        Provides outbound Internet connectivity and performs SNAT

Azure Standard Public IP	Provides the predictable public IP 4.224.18.198

Azure Virtual Machine	        Acts as the private workload generating outbound traffic

Ubuntu Server 24.04 LTS	        Operating system running on the VM

Azure Run Command	        Allows network testing directly from the VM

Azure Portal	                Used to create, configure, monitor, and test resources
